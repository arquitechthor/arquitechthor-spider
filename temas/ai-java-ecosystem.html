Qué es

Este bloque reúne las bibliotecas con las que una aplicación Java (o de cualquier lenguaje de la JVM, como Kotlin) llama a modelos de IA sin salir de su lenguaje. Son tres:

  • Spring AI: el proyecto oficial de Spring, para aplicaciones Spring Boot.
  • LangChain4j: una biblioteca independiente de cualquier marco, con integraciones para Spring Boot, Quarkus y otros.
  • MCP Java SDK: la implementación oficial en Java del protocolo MCP, para crear clientes y servidores MCP. Spring AI la usa por debajo para su soporte de MCP.

Las dos primeras cubren casi lo mismo (llamar a modelos de muchos proveedores, salida estructurada, herramientas, memoria, RAG, agentes) con estilos distintos. El SDK de MCP es de más bajo nivel: hace falta cuando quieres publicar tus propias herramientas como servidor MCP o controlar el protocolo directamente.

Siglas

  • JVM (Java Virtual Machine): la máquina virtual que ejecuta el código compilado de Java, Kotlin o Scala.
  • SDK (Software Development Kit): bibliotecas y herramientas para programar contra una plataforma o un protocolo.
  • MCP (Model Context Protocol): protocolo abierto para conectar modelos con herramientas y fuentes de datos.

Por qué importa

Python domina el entrenamiento de modelos, pero usarlos es otra cosa: los modelos se consumen como API por HTTP, así que cualquier lenguaje puede integrarlos. Para un equipo Java, hacerlo en Java evita un servicio aparte en Python y permite reutilizar lo que ya tiene: transacciones, seguridad, configuración, pruebas y monitorización.

Por eso estas bibliotecas han madurado deprisa y aparecen cada vez más en ofertas de backend Java. Como todo en esta área, cambian rápido: versiones, proveedores y nombres de clases se renuevan cada pocos meses.

Cuál elegir

  • Tu aplicación ya es Spring Boot: Spring AI, que sigue sus convenciones (starters, propiedades, beans, métricas).
  • No usas Spring, usas Quarkus o prefieres declarar el servicio como una interfaz: LangChain4j.
  • Quieres ofrecer tus herramientas a cualquier agente compatible: un servidor MCP, con el SDK directamente o con el soporte de MCP de Spring AI.

Por dónde empezar

  1. Model APIs y Tool Calling: qué hay debajo de cualquier biblioteca (una petición HTTP con mensajes y la respuesta del modelo).
  2. Spring AI si trabajas con Spring Boot, o LangChain4j si no.
  3. MCP y después el MCP Java SDK, cuando necesites conectar herramientas de forma estándar.
